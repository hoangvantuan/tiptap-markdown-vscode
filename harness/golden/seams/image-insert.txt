image insert seam — markdown written for a picked or downloaded image
each case: the document as it would be saved

## picker-simple
inserted: true
saved: "Before![photo](images/photo.png)"

## picker-space
# the saved path has a space: the destination must be wrapped in <...>
saved: "![my photo](<images/my photo.png>)"

## picker-space-reload
# the file holds <images/my photo.png>: it must translate for display, and back
display: "![my photo](https://file+.vscode-resource.vscode-cdn.net/ws/images/my%20photo.png)\n"
saved: "![my photo](<images/my photo.png>)"

## picker-anchor-moves

saved: "XXhe![pic](images/pic.png)llo"

## picker-cancel
# dialog cancelled: the host answers with no path
anchor taken: true
anchor taken again: false
unchanged: true

## remote-downloaded
